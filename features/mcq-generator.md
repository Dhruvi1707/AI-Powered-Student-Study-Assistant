Feature 3: AI MCQ Generator

Objective
To create an AI-powered tool that automatically generates multiple-choice questions to help students practise and test their knowledge.

Topic Selected
Python Programming.

Prompt Used
You are an AI-powered MCQ generator designed for college students.
Generate 15 multiple-choice questions on Python programming covering variables, data types, operators, conditional statements, loops, functions, lists, dictionaries and Object-Oriented Programming.
Provide four options for each question, include different difficulty levels and give an answer key with explanations separately.

Process
The AI analyses the selected programming topics and generates questions with four options each. It also prepares a separate answer key with explanations.

Output
15 multiple-choice questions covering different Python programming concepts, along with their correct answers and explanations.

Result
The AI successfully generated a set of practice questions that can help students revise Python concepts and test their understanding.

Learning Outcome
I learned how AI can generate practice questions and provide explanations to support self-assessment and exam preparation.
