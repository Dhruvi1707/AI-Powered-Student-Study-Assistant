# AI-Powered Student Study Assistant

## Project Overview

The AI-Powered Student Study Assistant is a mini-project designed to demonstrate how Artificial Intelligence can support students in their academic activities.

The project uses AI tools to simplify learning, generate practice questions, summarise study material and help students prepare for examinations.

It uses carefully designed prompts to perform different study-related tasks.

## Objectives

- Explore the practical applications of Artificial Intelligence in education.
- Understand how effective prompting improves AI-generated responses.
- Make studying and examination preparation easier.
- Develop practical AI skills through experimentation.

## Features

### 1. AI Study Planner
Generates personalised study timetables based on subjects, available study hours and examination dates.

### 2. AI Topic Explainer
Explains difficult academic and programming concepts in simple language with examples.

### 3. AI MCQ Generator
Generates multiple-choice questions with options, answers and explanations for practice.

### 4. AI Notes Summariser
Converts lengthy academic topics into short, organised revision notes.

### 5. AI Exam Preparation Assistant
Creates personalised examination preparation plans with revision schedules, practice activities and mock tests.

## Tools and Technologies Used

- ChatGPT / Claude – AI tools used to generate and test responses.
- Prompt Engineering – Used to provide clear instructions to AI tools.
- GitHub – Used to store project documentation, prompts and screenshots.
- Python – Used as an additional programming learning area.

## How the Project Works

1. The user provides a topic or study-related requirement.
2. A specific prompt is entered into an AI tool.
3. The AI processes the instructions and generates a response.
4. The generated output is reviewed for usefulness and accuracy.
5. The prompts, documentation and screenshots are saved in GitHub.

## Learning Outcomes

- Gained practical experience in using AI tools.
- Learned to write clear and effective prompts.
- Understood the importance of verifying AI-generated information.
- Explored different applications of AI in education.
- Improved understanding of basic programming concepts through additional Python learning.

## Project Conclusion

This project helped me understand how Artificial Intelligence can be used as a learning assistant. By developing and testing five different AI-based features, I gained practical experience in prompt engineering, responsible AI usage and the application of AI in education.

The project also helped me improve my technical knowledge and explore how AI can make academic learning more organised and efficient.
